# Life Expectancy Prediction Using Machine Learning

## Overview

This project applies machine learning regression techniques to predict life expectancy using demographic, health, and socioeconomic indicators. It explores data preprocessing, feature analysis, regression modeling, ensemble learning, and model evaluation.

The objective is to compare different regression algorithms and understand how well they predict life expectancy on unseen data.

## Objectives

- Explore and preprocess the life expectancy dataset.
- Handle missing values and examine potential outliers.
- Analyze relationships between input features and life expectancy.
- Implement and compare multiple regression algorithms.
- Evaluate models using standard regression metrics.
- Visualize model performance and feature importance.
- Apply cross-validation to study model generalization.

## Evaluation Metrics

- **R² Score:** Measures the proportion of target variance explained by a model. Higher is generally better.
- **MAE (Mean Absolute Error):** Measures the average absolute prediction error. Lower is better.
- **MSE (Mean Squared Error):** Measures the average squared prediction error. Lower is better.
- **RMSE (Root Mean Squared Error):** Expresses prediction error in the target variable's units. Lower is better.
